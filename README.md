# C exercises 💻

A repository dedicated to show my progress in learning the C programming language according to Universidade Presbiteriana Mackenzie's defined full course.

## How to run ▶️

First off, you'll have to compile the code running:

```bash
 gcc (name of exercise).c -o (name of exercise)
 ```

 Then you can run the code by simply running:

 ```bash
 ./(name of exercise)
 ```

Here's a full example on how it would look:

```bash
gcc ex1.c -o ex1
./ex1
```

## Lessons 📝

As previously mentioned, this repository will follow Mackenzie's course's timeline, following this structure:

* Lesson 1 -> Introduction to the C language
* Lesson 2 -> if/else statements
* Lesson 3 -> Functions
* Lesson 4 -> Arrays
* Lesson 5 -> Matrixes
* Lesson 6 & 7 -> exams
* Lesson 8 -> Linear & binary search
* Lesson 9 -> Bubble/selection/insertion sort & struct
* Lesson 10 -> Recursion & merge/quick sort
* Lesson 11 -> Pointers
